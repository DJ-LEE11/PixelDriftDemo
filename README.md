# Pixel Drift Demo

TikTok 小游戏 Demo。Pixel Drift Demo is a small portrait racing game built with Cocos Creator and adapted for TikTok Mini Games.

## Development environment

- Cocos Creator: 3.8.8
- TikTok Mini Games CLI (`@ttmg/cli`): 0.4.5
- TikTok client key: `mgne8cyzxjahjmfo`

## Project structure

- `assets/`: Cocos scenes and game scripts
- `scripts/adapt-tiktok.mjs`: adapts the Cocos Douyin Microgame build for TikTok Mini Games
- `docs/`: public Terms of Service and Privacy Policy pages
- `TIKTOK_DEBUG.md`: local build and TikTok debugging notes

Generated Cocos directories such as `build/`, `library/`, `temp/`, and `local/` are intentionally excluded from Git.
